# LITHOBLAST 3D

### Software de ingeniería minera

LITHOBLAST 3D es una aplicación de software orientada al ámbito de la ingeniería minera.

## Información de la versión

- **Versión:** 3.6.0
- **Distribución:** Gratuita inicialmente
- **Plataforma:** Windows de 64 bits
- **Formato:** Instalador ejecutable (.exe)

## Descarga

El instalador oficial está disponible en la sección [Releases](https://github.com/Lithoblast3D/LITHOBLAST-3D/releases).

## Instalación

1. Descarga el instalador.
2. Ejecuta el archivo `.exe`.
3. Sigue las instrucciones del asistente.
4. Abre LITHOBLAST 3D desde el acceso directo.
